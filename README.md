## 🚀 Featured projects

### [LearnSync AI](https://github.com/LouisBaruelo/LearnSyncAI) · Capstone
A web-based learning companion that lets Junior High students study on their own from their teacher's materials. It tracks what each student has mastered using Bayesian Knowledge Tracing and generates practice with AI. Piloted with 46 students and rated acceptable under ISO/IEC 25010.
- **My part:** group leader; built the student dashboard, the PlayMe review games (Crossword, Timed Trivia, Term Matching), and the admin module
- **Tech:** React · TypeScript · Tailwind CSS · Node.js · Express · Supabase · Gemini API

### [ISAMS](https://github.com/LouisBaruelo/ISAMS) · Faculty Requirements Submission Module
The academic management platform of PLP's College of Computer Studies, where faculty submit required documents and admins track and review them.
- **My part:** built the module end to end: uploads to Google Drive with OCR checks, status dashboards, deadline management, analytics, and an archive with batched ZIP downloads
- **Tech:** React · Vite · Node.js · Express · Supabase · Google Drive API · AG Grid · Vercel · Tauri

### [E-Commerce Microservices on AWS](https://github.com/LouisBaruelo/Four-week-microservice-dev) · Class project
An 8-service Node.js e-commerce platform built by 12 groups and deployed to AWS.
- **My part:** ECR team; created the Amazon ECR repositories for the service images and tested the REST APIs with Postman
- **Tech:** AWS (Amazon ECR) · Docker · Node.js · Postman
